# Sing-box 全场景跨端高级配置生成器

这是一个深度定制的 Python 自动化脚本，用于一键生成支持异地组网、智能分流、跨平台（兼容现代 1.13 与 苹果 iOS 老版本 1.11）的 Sing-box 高级路由配置文件。

## 🌟 核心特性

- **双协议支持**：同时输出 VLESS (REALITY) 和 Hysteria2 的配置，适应不同网络环境下的抗封锁与提速需求。
- **全平台通杀**：
  - `1.13` 文件夹：生成适配最新版 Sing-box 核心的现代化配置（全面采用 `rule_set` 取代已被废弃的 `geosite/geoip`）。
  - `1.11` 文件夹：内嵌自适应降级引擎，专门为 Apple iOS 端（旧版 1.11 核心）量身打造。彻底移除了 `strict_route` 与网卡绑定逻辑，根治了长期困扰 iOS 用户的“VPN 路由死循环”与“无可用网卡”报错。
- **动态分类收纳**：执行生成后，无需人工干预，脚本会自动把生成的几十份配置整齐归类进对应版本号的文件夹中。

## 🚀 场景全解析

脚本默认会为您生成高达 20 份极致优化的客户端配置文件，根据文件名后缀，它们分别对应以下使用场景：

### 1. 纯异地组网版 (`*-10.json`)
*   **流量走向**：仅当访问 `10.0.0.0/24` 和 `10.10.10.0/24` 等家庭/公司局域网 IP 时走隧道。
*   **适用人群**：只需远程访问 NAS、内网服务器，不需要任何科学上网翻墙功能的用户。

### 2. 全局代理版 (`*-lan.json`)
*   **流量走向**：所有网络请求（Global）无脑强制打包送入隧道，从远端服务器的出口离开。
*   **适用人群**：连接不安全的公共 Wi-Fi，或者需要完全隐藏本地真实 IP 的重度隐私保护用户。

### 3. 透明旁路由版 (`*-mihomo.json`)
*   **流量走向**：所有的流量打包送入隧道后，并不直接通过远端服务器发出，而是被重定向发往远端的 SOCKS 透明网关（`10.0.0.20:7890`，即 Mihomo/Clash 旁路由）。
*   **适用人群**：家里已经部署了软路由科学上网环境，希望人在外面时，也能无缝接入家里由软路由统一接管的翻墙网络。

### 4. 经典科学上网版 (`*-cn-direct.json`)
*   **流量走向**：
    1.  **国内直连**：精准匹配国内域名和 IP（通过 `geosite-cn` 和 `geoip-cn` 双重保障），走本地网络直连，不耗损代理节点流量，国内 App 极速满血。
    2.  **异地组网**：访问 10 段内网 IP 直接经隧道回家，无缝访问内网设备。
    3.  **海外代理**：非中国大陆和非内网的流量，全部交由远端的旁路由（`10.0.0.20`）接管。
*   **适用人群**：身处中国大陆，需要完美分流日常科学上网的用户（白名单模式）。

### 5. 极致隐私防护科学上网版 (`*-cn-direct-safe.json`)
*   **特性增强**：在 `cn-direct` 的基础上，将解析国内网站的 DNS 查询请求也进行了强制加密。通过隧道交由远端的 `10.0.0.1` 路由器处理。
*   **适用人群**：身处中国大陆的公共网络（如星巴克 Wi-Fi 或公司网络），不仅要翻墙，且不想让网管通过嗅探 DNS 数据包知道你正在访问哪个国内网站（如求职网站、摸鱼论坛）的用户。

### 6. 海外回国专用版 (`*-cn-proxy.json`)
*   **流量走向**：
    1.  **国内走代理**：命中中国大陆 IP 或域名的请求，将强制打包送入隧道，跨越重洋交由国内的节点代为访问。完美解除网易云音乐、Bilibili、爱奇艺的海外地域版权封锁。
    2.  **异地组网**：访问 10 段内网 IP 直接经隧道回国，随时管控国内家中的智能设备。
    3.  **海外直连**：看 Netflix、刷 YouTube 等本地流量完全直连，不占用昂贵的跨国节点带宽。
*   **适用人群**：身处海外（留学生、出差党），需要“翻墙回国”同时保留内网访问和海外本地极速冲浪的用户。

## 🛠️ 使用说明

环境要求：系统需安装 Python 3.8+ 及 `sing-box` (推荐 1.13+)、`openssl`。

```bash
# 执行生成脚本（以你的域名和端口为例）
python3 generate_singbox_bundle.py --domain example.com --vless-port 53742 --hy2-port 53743 -o ./output

# 脚本将会自动在 output 目录下生成服务端配置与各种分类好的客户端配置。
```
